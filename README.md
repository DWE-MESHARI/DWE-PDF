# DWE PDF

أدوات PDF للجامعة — تعمل بالكامل في المتصفح. لا يُرفع محتوى الملفات إلى الخادم.

## هيكل المشروع

```
DWE PDF/
├── index.html          ← الصفحة الرئيسية
├── css/style.css       ← التصميم
├── js/app.js           ← منطق الأدوات
├── libs/               ← مكتبات JavaScript محلية (بدون CDN)
├── assets/images/      ← الشعار (logo.png)
├── MERGE-CHECKLIST.md  ← قائمة الدمج والاختبار
└── README.md
```

## المكتبات المحلية (`libs/`)

| الملف | الاستخدام |
|--------|-----------|
| `pdf-lib.min.js` | دمج، تقسيم، تدوير، ترقيم، علامة مائية، حماية |
| `pdf.min.js` | عرض ومعاينة PDF |
| `pdf.worker.min.js` | عامل pdf.js |
| `jszip.min.js` | ملفات ZIP عند التقسيم/التحويل |
| `mammoth.browser.min.js` | Word → PDF |

## الأدوات المتاحة

- دمج، تقسيم، تدوير، حذف صفحات، استخراج صفحات، إعادة ترتيب، ترقيم
- تحرير PDF (نص، توقيع، تظليل، رسم)
- علامة مائية، حماية، فك الحماية، ضغط، قص
- PDF → صور، صور → PDF، Word → PDF

## الخصوصية

- كل معالجة PDF تتم في متصفح المستخدم.
- لا يوجد تسجيل دخول ولا إرسال ملفات إلى الخادم.
- لا يوجد تسجيل أحداث (audit logging) في هذا الإصدار.
- جميع مكتبات التشغيل داخل مجلد `libs/` ولا يعتمد الخادم المحلي على `npx` أو تنزيل حزم وقت التشغيل.
- ملفات Word والصور تُعالج محلياً مع تنقية HTML وحدود لحجم الملفات.

## النشر على IIS

1. انسخ مجلد المشروع بالكامل إلى مسار موقع IIS.
2. اجعل `index.html` مستنداً افتراضياً.
3. فعّل HTTPS.
4. افتح الموقع عبر `https://...` — لا تفتح `index.html` مباشرة عبر `file://`.

لا حاجة إلى PHP أو Node.js أو قاعدة بيانات للعمل الأساسي. سكربت التشغيل يستخدم
`py -m http.server` أو `python -m http.server` فقط، ولا ينفذ حزمة من الإنترنت.

عند النشر على IIS، اترك ملف `web.config` الموجود في جذر المشروع مفعلاً حتى
تُرسل رؤوس الحماية مثل CSP و`X-Frame-Options` و`nosniff`.

## التطوير المحلي

```powershell
# مثال: خادم ثابت مؤقت (إن وُجد Python)
cd "DWE PDF"
python -m http.server 8080
```

أو استخدم **IIS Express** / موقع IIS محلي.
